# TortoiseBotsManager Documentation

TortoiseBotsManager (TBM, `/tbm`) is the in-game window for the [TortoiseBots](https://github.com/Sagiroth/TortoiseBots) module. Every button sends one module command; the server decides what happens and answers. These pages describe the addon side. The bot behaviour behind each button is documented in the [module docs](https://github.com/Sagiroth/TortoiseBots/tree/main/docs).

## Start here

- [Getting started](play/getting-started.md) — install, log in your first bot, how orders are aimed.
- [What the addon can do](play/features.md) — every feature in one table, with what the server must enable.
